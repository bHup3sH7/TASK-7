# My First Responsive Website

This is a simple webpage with a top navigation bar and a hero section (the big banner you see at the top of most websites). It works on desktop, tablet, and mobile screens.

How to Open the File

Make sure these files are all in the same folder on your computer:

your-folder/
├── index.html
├── style.css
└── README.md

Find index.html and double-click it.
It will open in your web browser (Chrome, Firefox, Edge — any of them work).

That's it. No installs, no setup, no internet needed.

Want to see how it looks on mobile?
Press F12 on your keyboard → click the little phone/tablet icon at the top → drag the screen smaller to see it change.

## What We Learned

1. How to layout things side by side
   We used something called Flexbox — think of it like putting items in a row inside a box. You can tell the box: put one thing on the left, one in the middle, one on the right. That is how the navbar is arranged.
2. How to make the website change on different screen sizes
   We used media queries — these are like if/else rules for your design. For example: "if the screen is smaller than a tablet, stack things on top of each other instead of side by side." That is why the hero image moves below the text on mobile.
